# PASS 2 · Phase 1 · Lane STATISTICS — reconstructed claims (docs-only)

## 1. Claim + statistical guarantees
Claim (triage L62–67): CausalStress *identifies where estimators succeed, degrade, fail under synthetic stress without misleading comparisons across estimands, populations, failures, DGPs*; tiers reproducible ≠ valid ≠ representative. Rests on: **typed no-cross-scoring** — score only against a target's own truth, `scoreable = requested ∩ produced ∩ truth-available`, else machine `non_comparable` (§1.7; contracts.md). **Uncertainty**: CIs bootstrap-default or declared `meta$ci_type` (Art III §3.1); <90% replicate success ⇒ warning, CI=NA, `success=FALSE`. **Failure accounting**: per-task `success/error`, reconciliation `length(results)+nrow(errors)==nrow(tasks)`. **Gatekeeper** (Art IV): sharp-null placebo suite; ATT 95% CI covers 0 in ≥90% runs; QST "10/10 rule"; CI-less ⇒ "Unverified", systematic breach ⇒ "Non-Robust".

## 2. Assumptions for non-misleading comparison
Metrics well-posed in the DGP moment regime (L2/RMSE need finite variance — families `moment_regime rmse_valid=df>2`, Families §8.1.3). MC: independent seeds (Art II); QST oracle N=10⁶ immutable, independent unit noise, CRN (§1.4; Rmd v1.6.0). Denominators: report planned/attempted/succeeded/failed — silent `na.rm=TRUE` means are the flagged survivorship gap (horizon.md). Rank only within one `estimand_target_id` + scoring population (ATT-treated/ATE-all/QST-treated are distinct; population-QTE guardrail). Gatekeeper: per-DGP failure diagnostic not disqualifying (§4.2.4; horizon recalibration — kangschafer trap).

## 3. Per-estimand targets (cite)
- **ATT** — Structural/noise-free; scalar; treated; finite-sample (mean τ(X) over treated run sample). §1.3, §1.7.
- **ATE** — Structural; all units; finite-sample = full generated run sample (superpop only if DGP declares oracle, distinguished). §1.5; contracts Wave-1.
- **QST** — Distributional (signal+noise); curve; treated; oracle N=10⁶ over X|W=1 (not finite sample). §1.4.
- **CATE** — Structural conditional-mean τ(X) (not realized Y¹−Y⁰); unit; held-out = second governed draw; **`target_not_implemented` v0.2.0**. §1.6, Art II §2.2, §1.7.

## 4. Metric appropriateness under heavy tails (synth_heavytail, Cauchy mixture)
(a) Mean/L2 metrics are **not meaningful**: noise 0.8·N+0.2·Cauchy has undefined mean/variance, so "the population mean of realized outcomes is undefined, and any L2/MSE estimator is not well-posed" (heavytail.Rmd §2,§4); the sample mean "will never converge" (placebo_heavytail.Rmd §2). Const §1.3 prohibits sample-mean truth here; ATT *truth* stays well-defined via structural τ(X) (heavytail.Rmd §5), but that does not rescue mean_error/RMSE of a mean-targeting estimator (RMSE "fluctuates wildly ~8.0", §7). (b) Unstable ATT rankings are an **EXPECTED demonstration** ("L2 break"), not a defect — triage L18–22, "instability is the correct result". **Switch to QST/robust: yes in prose** — narratives recommend median/quantile targets (heavytail §2/§8; placebo_heavytail §2), sidecar `target: both`, §1.3 pairs DGP with QST. **Divergence flag:** the steer is narrative-only; no structural metric-invalidity gate exists on the point DGP (`metric_invalid_for_regime` is in the vocabulary but I found no documented application to synth_heavytail ATT), so nothing machine-level stops a naive mean-ATT ranking.
