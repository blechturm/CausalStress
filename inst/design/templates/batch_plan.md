## Review Protocol

A batch is the unit of Codex code review. Work one batch at a time.

For implementation or governance batches:

- finish the scoped batch;
- run targeted consistency checks;
- update the human-readable tickets, `tickets.yml`, and this batch plan together;
- stop and ask for Codex code review with an inline prompt;
- do not proceed to the next batch until Codex review findings are routed.

Supplemental maintainer or external-model review may be requested, but it does
not replace the required Codex review after each implemented batch.
