2. What This DGP Stresses (Intent)

This is a Sharp Null placebo with strong selection: \(Y_1 \equiv Y_0\) and \(\tau(X) \equiv 0\). Any estimator that detects an effect here fails the Gatekeeper check (Constitution Article IV).

This variant specifically stresses overlap violations via a sharply tilted propensity score.

3. Identification Assumptions (Explicit)

  • Selection on observables holds.
  • Overlap is intentionally stressed (propensity close to 0/1).
  • SUTVA holds.
  • Sharp Null: \(Y_1 \equiv Y_0\).

4. Mathematical Specification

Covariates: \(X_1, X_2, X_3, X_4, X_5 \sim \mathcal{N}(0, 1)\) independently.

Outcome (control): \[\mu_0(X) = 1 + X_1 + 0.5 X_2\]

Propensity (tilted): \[p(X) = \text{expit}(1.0 X_1 + 1.2 X_2)\]

Treatment effect (sharp null): \[\tau(X) \equiv 0\]

Noise is Gaussian: \(\varepsilon \sim \mathcal{N}(0, 0.5)\) and \(Y_1 \equiv Y_0\) pathwise.

5. Oracle Truth Definition

  • True ATT is zero by construction.
  • True QST is identically zero on the canonical grid.
