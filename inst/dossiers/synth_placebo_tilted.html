2. What This DGP Stresses (Intent)

This is a Sharp Null placebo with strong selection: \(Y_1 \equiv Y_0\) and \(\tau(X) \equiv 0\). Any estimator that detects an effect here fails the Gatekeeper check (Constitution Article IV).

This variant specifically stresses overlap violations via a sharply tilted propensity score.

3. Identification Assumptions (Explicit)

  • Selection on observables holds.
  • Overlap is intentionally stressed (propensity close to 0/1).
  • SUTVA holds.
  • Sharp Null: \(Y_1 \equiv Y_0\).

4. Mathematical Specification

Covariates: \(X_1, X_2, X_3, X_4, X_5 \sim \mathcal{N}(0, 1)\) independently.

Outcome (control): \[\mu_0(X) = 1 + X_1 + 0.5 X_2\]

Propensity (tilted): \[p(X) = \text{expit}(1.0 X_1 + 1.2 X_2)\]

Treatment effect (sharp null): \[\tau(X) \equiv 0\]

Noise is Gaussian: \(\varepsilon \sim \mathcal{N}(0, 0.5)\) and \(Y_1 \equiv Y_0\) pathwise.

5. Oracle Truth Definition

  • True ATT is zero by construction.
  • True QST is identically zero on the canonical grid.

function(n, seed = NULL, include_truth = TRUE, oracle_only = FALSE) {
  if (!is.null(seed)) {
    cs_set_rng(seed)
  }

  X1 <- stats::rnorm(n, mean = 0, sd = 1)
  X2 <- stats::rnorm(n, mean = 0, sd = 1)
  X3 <- stats::rnorm(n, mean = 0, sd = 1)
  X4 <- stats::rnorm(n, mean = 0, sd = 1)
  X5 <- stats::rnorm(n, mean = 0, sd = 1)

  mu0 <- 1 + X1 + 0.5 * X2
  tau <- rep(0, n)

  p <- stats::plogis(1.0 * X1 + 1.2 * X2)
  w <- stats::rbinom(n, size = 1L, prob = p)

  eps <- stats::rnorm(n, mean = 0, sd = 0.5)

  y0 <- mu0 + eps
  y1 <- y0
  if (isTRUE(oracle_only)) {
    return(list(df = tibble::tibble(w = w, y0 = y0, y1 = y1)))
  }
  y  <- ifelse(w == 1L, y1, y0)

  true_att <- cs_true_att(structural_te = tau, w = w)
  true_qst <- if (isTRUE(include_truth)) cs_get_oracle_qst("synth_placebo_tilted", version = "1.3.0") else NULL

  out <- list(
    df = tibble::tibble(
      y  = y,
      w  = w,
      y0 = y0,
      y1 = y1,
      p  = p,
      structural_te = tau,
      X1 = X1,
      X2 = X2,
      X3 = X3,
      X4 = X4,
      X5 = X5
    ),
    true_att = true_att,
    true_qst = true_qst,
    meta = list(
      dgp_id        = "synth_placebo_tilted",
      version       = "1.3.0",
      type          = "synthetic",
      params        = list(n = n, seed = seed),
      structural_te = tau
    )
  )

  cs_check_dgp_synthetic(out)
  out
}
